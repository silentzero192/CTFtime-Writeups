# Administrative Tasks - Tables

**Challenge Name:** `Administrative tasks - Tables`  
**Platform:** `CyberGame CTF`  
**Category:** `Forensics`  

1) **Goal (What was the task?)**
> We were given `Excel.xlsm` and told the flag was encrypted inside `flag1.zip`; the README hinted that four hidden messages inside the workbook form the password (SK-CERT{...} flag). Success meant extracting all hidden segments, deriving the password, decrypting `flag1.zip`, and retrieving the flag `SK-CERT{...}`.

2) **Key Clues (What mattered?)**
- README text: “All parts are in format `HIDDEN_MSG_x_{...}`” and password order `1423`.
- File structure: macro-enabled `.xlsm` file; `_Excel.xlsm.extracted` mirror exposing XML parts.
- Hidden strings embedded in shared strings, threaded comments, the `persons` metadata, and a complicated `sheet6` formula feeding VB-looking output.
- Target zip `flag1.zip` (30 bytes) with known flag format `SK-CERT{...}`.

3) **Plan (Your first logical approach)**
- Unzip the workbook to inspect XML data, grep for `HIDDEN_MSG` patterns, and map each hidden chunk to a workbook component.
- Locate the cells that output `HIDDEN_MSG_1` and `HIDDEN_MSG_2` (shared strings, comments) and parse them directly.
- Decode the VB-style snippet generated by `sheet6` formulas to recover `HIDDEN_MSG_3` and look into `xl/persons/person.xml` for `HIDDEN_MSG_4`.
- Concatenate the four inner parts in order 1-4-2-3, use that password to decrypt `flag1.zip`, and capture the flag.

4) **Steps (Clean execution)**
1. Unzipped `Excel.xlsm`, then searched XML for `HIDDEN_MSG` patterns; found part 1 in `xl/sharedStrings.xml`, part 2 inside `xl/comments1.xml`, and part 4 inside `xl/persons/person.xml`. → Verified the clues pointed to metadata/comments. → Still needed part 3.
2. Inspected `xl/worksheets/sheet6.xml`, noticed long `CHAR(ROUND(...))` formulas referencing `Resultz!`; evaluated the formula output to get lines of pseudo-VBA that defined two string constants. → Revealed the concatenation `NEDDIG` + `}6a0184c0{_3_GSM_` that reversed into `HIDDEN_MSG_3_{0c4810a6}`. → Now had all four parts.
3. Built password by ordering contents 1 → 4 → 2 → 3, yielding `8f2e8d9583b44f09aa30c9bf0c4810a6`; used it as the `-P` argument when unzipping `flag1.zip`. → Flag file decrypted successfully.

4. **Solution Summary (What worked and why?)**
   The workbook hid each `HIDDEN_MSG` inside different XML layers: shared strings for part 1, comments for part 2, threaded metadata for part 4, and a formula-generated VBA snippet for part 3. Extracting these and concatenating their payloads according to the README’s 1423 order produced the zip password. Decrypting `flag1.zip` with that password finally revealed the flag.

5) **Flag**
  `SK-CERT{L057_1N_3XC3L_5H3375}`

6) **Lessons Learned (make it reusable)**

- When an Excel workbook hides data, unzip it and grep XML/metadata; shared strings, comments, and persons metadata are quick wins.
- Complex-looking formulas often generate intermediary scripts—evaluate them manually or via a script to recover their textual output.
- Always trace any README-specified ordering (like 1423) before attempting decryption.
- Automating repeated steps (`solve.py`) saves time and keeps the workflow consistent.

8) **Personal Cheat Sheet (optional)**
- `unzip Excel.xlsm` → view raw XML content for hidden data.
- `rg -n "HIDDEN_MSG" -a` → find hidden strings in extracted XML/zip.
- `python solve.py` → reproduce part extraction, password generation, and flag decryption.
- `openpyxl`/Excel formulas → only necessary when formulas must be evaluated; manual parsing also works via `CHAR` patterns.
